GCP - IAM - Service Account

Criar Service Account de acesso

Este HTML ajuda o gestor a criar uma Service Account de provisionamento para o tecnico, conceder as roles do projeto e liberar impersonation sem distribuir chave JSON.

Use esta SA para provisionamento e operacao via gcloud --impersonate-service-account. Para runtime do Cloud Run, o ideal continua sendo uma SA dedicada com menos privilegios.

roles/secretmanager.adminSecret Manager

roles/redis.editorRedis

        
Permite uso do Memorystore em runtime.

      

      

        
roles/redis.adminRedis

roles/logging.logWriterLogging

        
Permite gravar logs no Cloud Logging.

      

      

        
roles/run.adminCloud Run

        
Permite criar e atualizar servicos no Cloud Run.

roles/storage.adminStorage

- O papel roles/iam.serviceAccountTokenCreator permite usar --impersonate-service-account.

      
- O papel roles/iam.serviceAccountUser permite anexar a SA a recursos quando necessario.

      
- Depois disso, o tecnico autentica com a propria conta e passa a operar como a SA.
